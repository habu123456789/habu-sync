# Project Memory

## Core
- Theme: 8 themes — Rose, Yellow/Sunrise, Blue/Ocean, Bhagwa, Krishna, Forest, Lotus, Dark. Glassmorphism.
- Typography: 'Dancing Script' headings, 'Quicksand' body text.
- Layout: Mantra → Gita Shlokas → Naam Jap → Hanuman Chalisa → Aarti → Festival Calendar → Clock.
- Auth: Email/Password & Google OAuth. No Twitter/X login.
- Constraints: Sanitize via DOMPurify. Display names only (no anonymous).
